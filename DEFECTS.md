# Defects

## Bug-001 -  Tooltip remains visible after mouse leaves the element

**Area:** Widgets > Tool Tips
**Status:** Open 
**Severity:** Low
**Priority:** Medium

### Description
The tooltip displayed for the "Hover me to see" button remains visible after the mouse pointer is moved away from the button

### Preconditions
- User is on the Tool Tips page
- Page has loaded successfully

### Steps to Reproduce
1. Hover over the "Hover me to see" button.
2. Confirm that the tooltip is displayed.
3. Move the mouse pointer away from the button

### Expected Result
The tooltip should disappear when the mouse pointer leaves the button

### Actual Result
Tooltip remains visible after the mouse pointer is out

### Environment
**Browser:** Google Chrome
**OS:** macOS
